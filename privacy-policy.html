Privacy Policy

This policy applies to the iBuben companion app, the iBuben custom keyboard extension, and the supporting services described below.

iBuben is operated by Albert Harutyunyan, an individual entrepreneur registered in Armenia, who is responsible for the data handling described in this policy. For privacy questions and requests, email ibuben.support@gmail.com.

iBuben does not require a separate iBuben user account. It does not sell personal data, display third-party advertising, or track you across apps or websites. Optional app statistics are described below.

Keyboard, Full Access, and data stored on your device

Ordinary typing is processed on your device. iBuben does not send what you type, your keystroke history, the surrounding contents of text fields, learned words, suggestions, clipboard content, or keyboard activity to our servers. The only keyboard text sent over the network is text you explicitly submit through the optional Translator as explained below.

Full Access is optional. Basic typing, local settings already available to the keyboard, and verified premium access do not require Full Access. It is needed only for features that require the keyboard to write shared local data or use the network, such as saving words learned or added from the keyboard, haptic feedback, and a translation request after your explicit action. Enabling Full Access by itself does not transmit text.

Learned words, personal-dictionary entries, keywords and text shortcuts, word-use counts, recent emoji, and preferences such as layout, key theme, gestures, symbols, and Translator settings may be stored locally on your device. They are used to provide and personalize keyboard features and are not uploaded to our servers.

Dictionary and keyword backups are created or imported only when you explicitly choose the action and a location in Files or iCloud Drive. iBuben does not automatically upload these files to the developer or Firebase. If you choose iCloud Drive, Apple processes the file under your iCloud settings and Apple’s privacy terms.

Language downloads and on-device features

When you download or update a language pack, the app requests public dictionary files and update information from Google Firebase Storage. The hosting service receives ordinary request data, including your IP address and the requested file, which can reveal the selected language pack. Downloading does not upload typed text, learned words, or your personal dictionary. Installed dictionaries and keyboard predictions are processed locally.

Where available, AI Rewrite and AI Emojis use Apple’s on-device model. The text and relevant context you choose for these features are processed on the device; iBuben does not send them to an external AI service or keep a server-side transcript. Keyboard calculator expressions and results are also processed locally.

Optional Translator

The Translator is off by default. Opening it, choosing a language, or typing normally does not send text. A request begins only after you explicitly tap Translate. The submitted source is the text currently shown in the Translator: it starts with the text you selected in the host app and may include edits you make inside the Translator before submitting. iBuben does not read or send the surrounding document text. Replacing the selected text with a translation requires a separate explicit action.

For a translation request, the keyboard sends over HTTPS the submitted source text (up to 1,000 Unicode characters), the chosen target-language code, an optional source-language code when you choose a source manually, a random request identifier, and a random anonymous installation identifier to the iBuben translation proxy hosted on Google Cloud/Firebase. When Auto is selected, Yandex Cloud Translate detects the source language from the submitted text. The proxy sends the source text, language codes, and request identifier to Yandex Cloud Translate and requests that provider-side data logging be disabled.

The iBuben translation proxy does not store or log the submitted text or translated text. Its operational logs contain only metadata such as request identifier, language code, character count, latency, status, and normalized error type. The hosting infrastructure necessarily processes the request’s IP address. The proxy uses the IP address and anonymous installation identifier only in memory to create rotating, non-reversible keyed hashes for abuse prevention and daily limits; raw IP addresses and raw installation identifiers are not stored in the rate-limit records. Rate-limit records contain only request and character counts and are marked to expire approximately eight days after creation, subject to scheduled database cleanup.

The current service limit is 1,000 submitted input characters per anonymous installation per UTC calendar day. The counter changes with the next UTC date. Translation results are kept only in the keyboard extension’s temporary memory and are cleared when you close the Translator, the selection changes, iOS reports memory pressure, or the extension process ends.

Optional app statistics

App statistics are off by default. Where this option is available, users aged 18 or over can turn it on to help improve iBuben. Declining does not limit app or keyboard features. Before you enable it, no statistics are sent to PostHog and no past activity is saved for later sending.

Statistics cover only the main iBuben app: sections opened, a small set of button actions, setup completion, and rounded time with the app on screen. They never include keyboard activity, typed text, messages, clipboard contents, learned words, translations, feedback contents, photos, payment details, or other sensitive content. We do not create personal profiles or record the screen.

PostHog EU processes these limited statistics on our behalf to improve the app. Each event gets a new random technical code, without a shared user, device, or session identifier. The App Store country is checked to determine availability and included as a market label in events; it is not your physical location. We do not send advertising identifiers, permanent device identifiers, or GPS location. Network services necessarily receive your IP address when delivering a request; storing IP addresses in the statistics and using them to determine location are disabled.

You can turn app statistics off at any time in About iBuben. This stops further collection and sending and clears pending events on the device. It does not automatically delete events already received. Statistics are kept only as long as reasonably necessary to understand and improve the app. You can request deletion through Contact Developer or the email below; because events are not linked to your name or account, we may be unable to find a particular past event.

Optional notifications

If you opt in to notifications, the companion app uses Firebase Cloud Messaging (FCM) and Apple Push Notification service (APNs) to deliver occasional app updates and useful tips. These services process an APNs token, a Firebase app installation identifier, and technical app and device information needed to address, deliver, and diagnose notifications, such as device model, language, time zone, operating-system version, app identifier, and app version. FCM may process non-personal delivery and diagnostic data. Firebase Analytics is linked only in the companion app, with data collection disabled. The keyboard extension does not use Firebase notification or analytics SDKs, and notification services do not receive keyboard text, learned words, suggestions, clipboard content, or keyboard activity.

Notifications are optional. You can disable them in iBuben or iOS Settings. When you opt out in iBuben, the app disables messaging and requests deletion of its FCM registration token and topic subscription; if the device is temporarily offline, cleanup is retried later.

Feedback, support, and Photos

If you submit feedback, the name, email address, message category, message, app language and version, and any image you choose to attach are sent only to deliver, diagnose, and respond to your request. Feedback is routed through Google Apps Script and Google’s email services. If you contact the developer directly, your email provider also processes the message under its own terms. This information is not used for advertising or tracking.

If you choose Save Story Image, iBuben requests add-only Photos access solely to save the prepared image. iBuben does not read, scan, or upload your photo library. If you attach an image to feedback, only the image you explicitly select is processed for that submission.

Purchases, subscriptions, and premium access

Purchases and subscriptions are processed by Apple through StoreKit. iBuben does not receive your Apple ID, payment card, bank-account information, or other payment credentials.

Eligible users may also receive a one-time 7-day App Trial. The App Trial is provided by iBuben, is separate from an Apple subscription introductory offer, starts only after the user explicitly chooses to begin it, does not create a purchase or subscription, does not charge the user, and does not renew automatically. Subscription plans such as Monthly and Yearly, and a Lifetime purchase, remain separate Apple in-app purchases. If Apple separately displays an introductory offer for Yearly, that offer is part of the subscription and its billing and renewal terms are shown in Apple’s confirmation sheet.

To determine App Trial eligibility, validate premium access, restore purchases, and react to renewals, billing status, refunds, or revocations, the companion app and iBuben’s purchase-verification service may process Apple-signed App Transaction, transaction, renewal, and App Store Server Notification data. This may include Apple-generated app-transaction, transaction, and original-transaction identifiers; product identifier; App Store environment; purchase and expiration dates; grace-period, billing, ownership, and revocation status; and notification-processing status. The service is hosted on Google Cloud/Firebase and may query Apple’s App Store Server API. These records do not contain keyboard text, an Apple ID, advertising identifiers, payment credentials, or a device fingerprint.

App Trial eligibility is associated with Apple’s verified app-transaction identity for the Apple Account used for Media & Purchases. iBuben receives the Apple-signed account-level identifier, not the Apple ID, name, or email address. This allows the same account’s App Trial history to remain consistent across reinstallations and devices.

Purchase and trial-history records are retained for as long as reasonably necessary to provide and restore entitlement, preserve App Trial eligibility and use history and any Apple offer history, process renewals, refunds, and revocations, prevent fraud or repeated trial use, and meet security or legal obligations. Deleting or reinstalling the app does not delete Apple’s purchase history or these necessary entitlement records. Subscription cancellation and Apple purchase-history controls are managed through Apple.

Private purchase reports

Our purchase service maintains private operational reports about subscriptions, trials and purchase events. Limited alerts may be delivered to the developer through Telegram: a pseudonymous customer number or event reference, plan, amount and currency when supplied by Apple, App Store country, dates, and renewal status. These reports do not include your Apple ID, name, email, payment credentials, or keyboard text. This purchase-service processing is separate from optional app-usage statistics and is not controlled by that switch.

Service providers and international processing

Depending on the feature you choose, data may be processed by Apple (StoreKit, APNs, and iCloud Drive), Google/Firebase/Google Cloud (language downloads, notifications, service hosting, rate limiting, and purchase verification), Google Apps Script and email services (feedback), Yandex Cloud Translate (translation), PostHog EU (optional app statistics), and Telegram (private purchase-service alerts). Processing may occur in countries other than your own. We use these providers only to deliver the functions described above under their applicable terms and privacy arrangements. We do not permit them to use keyboard text or other submitted content for iBuben advertising or cross-app tracking.

Retention, deletion, and your choices

You can delete learned words and reset keyboard data in the app, delete backup files from the location you selected, disable the Translator, notifications, or app statistics in iBuben, and change Full Access, Photos, and notification permissions in iOS Settings. Information submitted through feedback is kept only as long as reasonably necessary to respond, resolve the issue, and meet security or legal obligations.

You may ask questions or request deletion of data controlled by iBuben by emailing ibuben.support@gmail.com. Some information may need to be retained where required to maintain purchase or trial integrity, complete a request, prevent abuse, or comply with law. Data controlled by Apple, Google, Yandex, your email provider, Files, or iCloud must also be managed through that provider’s controls. Please do not send keyboard text or payment credentials in a privacy request.

Changes to this policy

We may update this Privacy Policy when iBuben’s features or data-handling practices change. The updated version and its revision date will be published on this page.

Contact

Կամընտիր Թարգմանիչ

Թարգմանիչը լռելյայն անջատված է։ Այն բացելը, լեզու ընտրելը կամ սովորական մուտքագրումը տեքստ չի ուղարկում։ Հարցումն սկսվում է միայն այն ժամանակ, երբ դուք հստակ սեղմում եք «Թարգմանել»։ Ուղարկվում է Թարգմանիչում այդ պահին ցուցադրվող տեքստը․ սկզբում դա այն հավելվածում ձեր ընտրած հատվածն է, որտեղ օգտագործում եք ստեղնաշարը, և այն կարող եք խմբագրել Թարգմանիչի ներսում մինչև ուղարկելը։ iBuben-ը չի կարդում կամ ուղարկում փաստաթղթի շրջակա տեքստը։ Ընտրված հատվածը թարգմանությամբ փոխարինելու համար անհրաժեշտ է առանձին հստակ գործողություն։

Թարգմանության հարցման ժամանակ ստեղնաշարը HTTPS-ով iBuben-ի՝ Google Cloud/Firebase-ում տեղակայված թարգմանության միջնորդ սերվերին է ուղարկում ներկայացված տեքստը (մինչև 1 000 Unicode սիմվոլ), նպատակային լեզվի կոդը, սկզբնական լեզուն ձեռքով ընտրելու դեպքում՝ դրա կոդը, հարցման պատահական նույնացուցիչը և տեղադրման պատահական անանուն նույնացուցիչը։ «Ավտոմատ» տարբերակի դեպքում Yandex Cloud Translate-ը որոշում է սկզբնական լեզուն ուղարկված տեքստից։ Միջնորդ սերվերը սկզբնական տեքստը, լեզուների կոդերն ու հարցման նույնացուցիչը փոխանցում է Yandex Cloud Translate-ին և պահանջում է անջատել մատակարարի կողմից տվյալների գրանցումը։

iBuben-ի թարգմանության միջնորդ սերվերը չի պահում և չի գրանցում ներկայացված կամ թարգմանված տեքստը։ Գործառնական գրանցամատյանները պարունակում են միայն այնպիսի մետատվյալներ, ինչպիսիք են հարցման նույնացուցիչը, լեզվի կոդը, նիշերի քանակը, տևողությունը, կարգավիճակը և նորմալացված սխալի տեսակը։ Հոսթինգի ենթակառուցվածքը տեխնիկապես մշակում է հարցման IP հասցեն։ Միջնորդ սերվերն IP հասցեն և տեղադրման անանուն նույնացուցիչն օգտագործում է միայն օպերատիվ հիշողությունում՝ չարաշահումներից պաշտպանվելու և օրական սահմանաչափերը կիրառելու համար ամեն օր փոխվող, չվերականգնվող բանալիավորված հեշեր ստեղծելու նպատակով։ Սահմանաչափերի գրառումներում սկզբնական IP հասցեները և տեղադրման սկզբնական նույնացուցիչները չեն պահվում։ Այդ գրառումները պարունակում են միայն հարցումների ու նիշերի քանակները և նշվում են ստեղծումից մոտ ութ օր անց ջնջվելու համար՝ տվյալների բազայի պլանավորված մաքրման ընթացքում։

Ծառայության ընթացիկ սահմանաչափը մեկ անանուն տեղադրման համար յուրաքանչյուր UTC օրացուցային օրվա ընթացքում ուղարկված 1 000 մուտքային սիմվոլ է։ Հաշվիչը փոխվում է հաջորդ UTC ամսաթվին անցնելիս։ Թարգմանության արդյունքները պահվում են միայն ստեղնաշարի ընդլայնման ժամանակավոր օպերատիվ հիշողությունում և ջնջվում են, երբ փակում եք Թարգմանիչը, ընտրությունը փոխվում է, iOS-ը հայտնում է հիշողության պակասի մասին կամ ընդլայնման գործընթացն ավարտվում է։

Հավելվածի կամընտիր վիճակագրություն

Հավելվածի վիճակագրությունը լռելյայն անջատված է։ Այն երկրներում, որտեղ այս տարբերակը հասանելի է, 18 տարին լրացած օգտատերերը կարող են այն միացնել՝ iBuben-ը բարելավելու համար։ Հրաժարվելը չի սահմանափակում հավելվածի կամ ստեղնաշարի գործառույթները։ Մինչև այն միացնելը PostHog-ին վիճակագրություն չի ուղարկվում, իսկ նախորդ գործողությունները հետագայում ուղարկելու համար չեն պահվում։

Վիճակագրությունը վերաբերում է միայն iBuben-ի հիմնական հավելվածին՝ բացված բաժիններին, որոշ կոճակների սեղմումներին, սկզբնական կարգավորման ավարտին և հավելվածն էկրանին բաց պահելու կլորացված տևողությանը։ Այն երբեք չի ներառում ստեղնաշարի օգտագործումը, մուտքագրված տեքստը, հաղորդագրությունները, փոխանակման բուֆերի պարունակությունը, սովորած բառերը, թարգմանությունները, հետադարձ կապի բովանդակությունը, լուսանկարները, վճարային տվյալները կամ այլ զգայուն բովանդակություն։ Մենք անձնական պրոֆիլներ չենք ստեղծում և էկրանը չենք ձայնագրում։

PostHog EU-ն մեր անունից մշակում է այս սահմանափակ վիճակագրությունը՝ հավելվածը բարելավելու համար։ Յուրաքանչյուր իրադարձության համար ստեղծվում է նոր պատահական տեխնիկական կոդ՝ առանց օգտատիրոջ, սարքի կամ այցելության ընդհանուր նույնացուցիչի։ App Store-ի երկիրը ստուգվում է գործառույթի հասանելիության համար և ներառվում իրադարձություններում որպես շուկայի նշում․ դա ձեր ֆիզիկական գտնվելու վայրը չէ։ Մենք չենք ուղարկում գովազդային նույնացուցիչներ, սարքի մշտական նույնացուցիչներ կամ GPS կոորդինատներ։ Հարցումն ուղարկելու ընթացքում ցանցային ծառայություններն անխուսափելիորեն ստանում են ձեր IP հասցեն, սակայն վիճակագրությունում IP հասցեների պահպանումը և դրանցով գտնվելու վայրի որոշումն անջատված են։

Հավելվածի վիճակագրությունը ցանկացած պահի կարող եք անջատել «iBuben-ի մասին» բաժնում։ Դրանից հետո հավաքումն ու ուղարկումը դադարում են, իսկ սարքում դեռ չուղարկված իրադարձությունները ջնջվում են։ Արդեն ստացված իրադարձություններն ինքնաբերաբար չեն ջնջվում։ Վիճակագրությունը պահվում է միայն այնքան ժամանակ, որքան ողջամտորեն անհրաժեշտ է հավելվածը հասկանալու և բարելավելու համար։ Ջնջում կարող եք խնդրել «Կապ ստեղծողի հետ» բաժնից կամ ստորև նշված էլ․ հասցեով․ քանի որ իրադարձությունները կապված չեն ձեր անվան կամ հաշվի հետ, հնարավոր է՝ չկարողանանք գտնել որոշակի նախորդ իրադարձություն։

Օպցիոնալ ծանուցումներ

Եթե համաձայնում եք ստանալ ծանուցումներ, հիմնական հավելվածը ժամանակ առ ժամանակ նորություններ և օգտակար խորհուրդներ ուղարկելու համար օգտագործում է Firebase Cloud Messaging (FCM) և Apple Push Notification service (APNs) ծառայությունները։ Այդ ծառայությունները մշակում են APNs-ի թոքենը, Firebase-ում հավելվածի տեղադրման նույնացուցիչը և ծանուցումները հասցեագրելու, առաքելու ու ախտորոշելու համար անհրաժեշտ տեխնիկական տվյալները՝ սարքի մոդելը, լեզուն, ժամային գոտին, օպերացիոն համակարգի տարբերակը, հավելվածի նույնացուցիչն ու տարբերակը։ FCM-ը կարող է մշակել նաև անձի հետ չկապված առաքման և ախտորոշման տվյալներ։ Firebase Analytics-ը ներառված է միայն հիմնական հավելվածում, իսկ տվյալների հավաքումն անջատված է։ Ստեղնաշարի ընդլայնումը չի օգտագործում Firebase-ի ծանուցումների կամ վերլուծական SDK-ները, իսկ ծանուցումների ծառայությունները չեն ստանում ստեղնաշարի տեքստը, սովորած բառերը, առաջարկները, փոխանակման բուֆերի պարունակությունը կամ ստեղնաշարի օգտագործման տվյալները։

Ծանուցումները կամընտիր են։ Դրանք կարող եք անջատել iBuben-ում կամ iOS-ի Կարգավորումներում։ iBuben-ում հրաժարվելու դեպքում հավելվածն անջատում է հաղորդագրությունների ծառայությունը և խնդրում ջնջել FCM-ի գրանցման թոքենն ու թեմայի բաժանորդագրությունը։ Եթե սարքը ժամանակավորապես անցանց է, մաքրումը կրկին կփորձվի ավելի ուշ։

Հետադարձ կապ, աջակցություն և Photos

Եթե ուղարկում եք հետադարձ կապ, ձեր նշած անունը, էլ․ հասցեն, հաղորդագրության կատեգորիան, տեքստը, հավելվածի լեզուն ու տարբերակը և ձեր ընտրությամբ կցված պատկերը փոխանցվում են միայն դիմումը հասցնելու, խնդիրը ուսումնասիրելու և պատասխանելու համար։ Դիմումները փոխանցվում են Google Apps Script-ի և Google-ի էլփոստային ծառայությունների միջոցով։ Եթե ստեղծողին գրում եք անմիջապես, ձեր էլփոստային ծառայությունը նույնպես մշակում է հաղորդագրությունն իր պայմանների համաձայն։ Այս տվյալները չեն օգտագործվում գովազդի կամ հետևման նպատակով։

Եթե ընտրում եք պահպանել Story-ի նկարը, iBuben-ը Photos-ում միայն ավելացնելու թույլտվություն է խնդրում՝ պատրաստի նկարը պահպանելու համար։ iBuben-ը չի կարդում, չի դիտարկում և չի վերբեռնում ձեր լուսանկարների գրադարանը։ Եթե հետադարձ կապին նկար եք կցում, տվյալ դիմումի համար մշակվում է միայն ձեր հստակ ընտրած նկարը։

Գնումներ, բաժանորդագրություններ և պրեմիում հասանելիություն

Գնումներն ու բաժանորդագրությունները մշակվում են Apple-ի կողմից՝ StoreKit-ի միջոցով։ iBuben-ը չի ստանում ձեր Apple ID-ն, վճարային քարտի կամ բանկային հաշվի տվյալները և վճարման այլ տվյալներ։

Իրավասու օգտատերերին կարող է տրամադրվել նաև մեկանգամյա 7-օրյա App Trial։ App Trial-ը տրամադրվում է iBuben-ի կողմից, առանձին է Apple-ի բաժանորդագրության ներածական առաջարկից, սկսվում է միայն օգտատիրոջ հստակ ընտրությունից հետո, գնում կամ բաժանորդագրություն չի ստեղծում, վճար չի գանձում և ինքնաբերաբար չի երկարաձգվում։ Բաժանորդագրությունները, այդ թվում՝ Monthly-ն ու Yearly-ն, և Lifetime գնումը մնում են Apple-ի առանձին ներհավելվածային գնումներ։ Եթե Apple-ը Yearly-ի համար առանձին ներածական առաջարկ է ցուցադրում, այն բաժանորդագրության մաս է, իսկ վճարման ու երկարաձգման պայմանները ներկայացվում են Apple-ի հաստատման պատուհանում։

App Trial-ի իրավասությունը որոշելու, պրեմիում հասանելիությունը հաստատելու, գնումները վերականգնելու, ինչպես նաև երկարաձգումներին, վճարման կարգավիճակին, գումարի վերադարձին կամ հասանելիության հետկանչին արձագանքելու համար հիմնական հավելվածը և iBuben-ի գնումների ստուգման ծառայությունը կարող են մշակել Apple-ի ստորագրած App Transaction-ի, գործարքների, երկարաձգումների և App Store Server Notification-ի տվյալները։ Դրանք կարող են ներառել Apple-ի ստեղծած հավելվածային գործարքի, գործարքի և սկզբնական գործարքի նույնացուցիչները, ապրանքի նույնացուցիչը, App Store-ի միջավայրը, գնման ու ավարտի ամսաթվերը, արտոնյալ ժամանակահատվածի, վճարման, սեփականության և հետկանչի կարգավիճակները, ինչպես նաև ծանուցման մշակման կարգավիճակը։ Ծառայությունը տեղակայված է Google Cloud/Firebase-ում և կարող է հարցումներ կատարել Apple-ի App Store Server API-ին։ Այս գրառումները չեն պարունակում ստեղնաշարի տեքստ, Apple ID, գովազդային նույնացուցիչներ, վճարային տվյալներ կամ սարքի թվային մատնահետք։

App Trial-ի իրավասությունը կապվում է Media & Purchases-ի համար օգտագործվող Apple Account-ի՝ Apple-ի կողմից հաստատված հավելվածային գործարքի նույնացուցիչին։ iBuben-ը ստանում է Apple-ի ստորագրած հաշվի մակարդակի նույնացուցիչը, ոչ թե Apple ID-ն, անունը կամ էլ․ փոստի հասցեն։ Սա թույլ է տալիս նույն հաշվի App Trial-ի պատմությունը պահպանել հավելվածը կրկին տեղադրելիս և այլ սարքի անցնելիս։

Գնումների և փորձաշրջանի պատմության գրառումները պահվում են այնքան ժամանակ, որքան ողջամտորեն անհրաժեշտ է հասանելիությունն ապահովելու և վերականգնելու, App Trial-ի իրավասության ու օգտագործման պատմությունը և Apple-ի ցանկացած առաջարկի պատմությունը պահպանելու, երկարաձգումները, վերադարձներն ու հետկանչերը մշակելու, խարդախությունը կամ փորձաշրջանի կրկնակի օգտագործումը կանխելու և անվտանգության կամ իրավական պահանջները կատարելու համար։ Հավելվածը ջնջելը կամ կրկին տեղադրելը չի ջնջում Apple-ի գնումների պատմությունը կամ հասանելիության համար անհրաժեշտ այս գրառումները։ Բաժանորդագրության չեղարկումն ու Apple-ի գնումների պատմության կառավարումը կատարվում են Apple-ի միջոցով։

Գնումների ծառայողական հաշվետվություններ

Գնումների ծառայությունը պահում է բաժանորդագրությունների, փորձաշրջանների և գնումների փակ ծառայողական հաշվետվություններ։ Telegram-ի միջոցով մշակողին կարող են ուղարկվել սահմանափակ ծանուցումներ՝ գնորդի պայմանական համար կամ իրադարձության կոդ, սակագին, Apple-ի տրամադրած գումարն ու արժույթը, App Store-ի երկիրը, ամսաթվերը և երկարաձգման կարգավիճակը։ Դրանք չեն պարունակում ձեր Apple ID-ն, անունը, էլ․ հասցեն, վճարային տվյալները կամ ստեղնաշարի տեքստը։ Գնումների ծառայության այս մշակումը առանձին է հավելվածի կամավոր վիճակագրությունից և չի կառավարվում դրա անջատիչով։

Ծառայություններ մատուցողներ և միջազգային մշակում

Կախված ձեր ընտրած գործառույթից՝ տվյալները կարող են մշակվել Apple-ի (StoreKit, APNs և iCloud Drive), Google/Firebase/Google Cloud-ի (լեզուների ներբեռնում, ծանուցումներ, ծառայությունների հոսթինգ, սահմանաչափերի կիրառում և գնումների ստուգում), Google Apps Script-ի և էլփոստային ծառայությունների (հետադարձ կապ), Yandex Cloud Translate-ի (թարգմանություն), PostHog EU-ի (հավելվածի կամընտիր վիճակագրություն) և Telegram-ի (գնումների ծառայության փակ ծանուցումներ) կողմից։ Մշակումը կարող է կատարվել ձեր երկրից դուրս։ Մենք այս ծառայություններն օգտագործում ենք միայն վերը նկարագրված գործառույթներն ապահովելու համար նրանց կիրառելի պայմանների և տվյալների մշակման կանոնների համաձայն։ Մենք նրանց թույլ չենք տալիս ստեղնաշարի տեքստը կամ ներկայացված այլ բովանդակությունն օգտագործել iBuben-ի գովազդի կամ տարբեր հավելվածներում օգտատերերին հետևելու համար։

Политика конфиденциальности

Эта политика относится к основному приложению iBuben, расширению клавиатуры iBuben и вспомогательным сервисам, описанным ниже.

Оператор iBuben — Albert Harutyunyan, индивидуальный предприниматель, зарегистрированный в Армении. Он отвечает за описанную в этой политике обработку данных. По вопросам конфиденциальности и запросам напишите на ibuben.support@gmail.com.

Для iBuben не требуется отдельная учётная запись пользователя. iBuben не продаёт персональные данные, не показывает стороннюю рекламу и не отслеживает вас в других приложениях или на сайтах. Необязательная статистика приложения описана ниже.

Клавиатура, «Полный доступ» и данные на устройстве

Обычный ввод обрабатывается на вашем устройстве. iBuben не отправляет на наши серверы введённый вами текст, историю нажатий, окружающее содержимое текстовых полей, запомненные слова, подсказки, содержимое буфера обмена или сведения об использовании клавиатуры. Единственный текст, который клавиатура передаёт по сети, — текст, явно отправленный вами через необязательный Переводчик, как описано ниже.

«Полный доступ» необязателен. Он не требуется для обычного ввода, доступных клавиатуре локальных настроек и подтверждённого премиум-доступа. Он нужен только функциям, которым необходимо записывать данные в общий локальный контейнер или обращаться к сети, например для сохранения запомненных или добавленных с клавиатуры слов, тактильного отклика и отправки запроса на перевод после вашего явного действия. Само предоставление «Полного доступа» не передаёт текст.

Запомненные слова, записи личного словаря, ключевые слова и текстовые сокращения, частота использования слов, недавние emoji, а также настройки раскладки, оформления клавиш, жестов, символов и Переводчика могут храниться локально на вашем устройстве. Они используются для работы и персонализации клавиатуры и не загружаются на наши серверы.

Резервные копии словаря и ключевых слов создаются или импортируются только тогда, когда вы явно выбираете действие и место в приложении «Файлы» или iCloud Drive. iBuben не загружает эти файлы разработчику или в Firebase автоматически. При выборе iCloud Drive файл обрабатывается Apple в соответствии с вашими настройками iCloud и условиями конфиденциальности Apple.

Загрузка языков и функции на устройстве

При загрузке или обновлении языкового пакета приложение запрашивает общедоступные словари и сведения об обновлениях из Google Firebase Storage. Сервис размещения получает обычные данные запроса, включая IP-адрес и запрошенный файл, по которому можно определить выбранный языковой пакет. При загрузке не отправляются введённый текст, запомненные слова или личный словарь. Установленные словари и подсказки клавиатуры обрабатываются на устройстве.

Там, где доступны AI Rewrite и AI Emojis, они используют модель Apple на устройстве. Выбранный вами текст и необходимый контекст обрабатываются локально; iBuben не отправляет их во внешний AI-сервис и не хранит историю на сервере. Выражения и результаты калькулятора клавиатуры также обрабатываются на устройстве.

Необязательный Переводчик

Переводчик по умолчанию выключен. Его открытие, выбор языка или обычный ввод не отправляют текст. Запрос начинается только после явного нажатия «Перевести». Отправляется текст, который в этот момент показан в Переводчике: сначала это фрагмент, выделенный в приложении, где вы используете клавиатуру, но перед отправкой его можно отредактировать внутри Переводчика. iBuben не читает и не отправляет окружающий текст документа. Для замены выделенного фрагмента переводом требуется отдельное явное действие.

При запросе клавиатура передаёт по HTTPS отправляемый текст (не более 1 000 символов Unicode), код целевого языка, код исходного языка при его ручном выборе, случайный идентификатор запроса и случайный анонимный идентификатор установки на прокси перевода iBuben, размещённый в Google Cloud/Firebase. При выборе «Авто» Yandex Cloud Translate определяет исходный язык по отправленному тексту. Прокси передаёт исходный текст, коды языков и идентификатор запроса в Yandex Cloud Translate и запрашивает отключение журналирования данных на стороне поставщика.

Прокси перевода iBuben не хранит и не записывает в журналы отправленный или переведённый текст. Технические журналы содержат только такие метаданные, как идентификатор запроса, код языка, число символов, длительность, статус и нормализованный тип ошибки. Инфраструктура хостинга технически обрабатывает IP-адрес запроса. Прокси использует IP-адрес и анонимный идентификатор установки только в оперативной памяти, чтобы создавать ежедневно меняющиеся необратимые защищённые хеши для предотвращения злоупотреблений и применения суточных лимитов. Исходные IP-адреса и идентификаторы установки не сохраняются в записях лимитов. Такие записи содержат только количество запросов и символов и помечаются для удаления примерно через восемь дней после создания в ходе плановой очистки базы данных.

Текущий лимит сервиса — 1 000 отправленных входных символов на одну анонимную установку за календарный день по UTC. Счётчик меняется при наступлении следующей даты UTC. Результаты перевода хранятся только во временной памяти расширения клавиатуры и удаляются при закрытии Переводчика, изменении выделения, предупреждении iOS о нехватке памяти или завершении процесса расширения.

Необязательная статистика приложения

Статистика приложения по умолчанию выключена. Там, где эта возможность доступна, пользователи от 18 лет могут включить её, чтобы помочь улучшать iBuben. Отказ не ограничивает функции приложения или клавиатуры. До включения статистика не отправляется в PostHog, а прошлые действия не сохраняются для последующей отправки.

Статистика касается только основного приложения iBuben: открытых разделов, небольшого набора нажатий на кнопки, завершения начальной настройки и округлённого времени, пока приложение открыто на экране. В неё никогда не входят действия в клавиатуре, введённый текст, сообщения, содержимое буфера обмена, запомненные слова, переводы, содержимое обращений, фотографии, платёжные данные или другое чувствительное содержимое. Мы не создаём личные профили и не записываем экран.

PostHog EU обрабатывает эту ограниченную статистику по нашему поручению для улучшения приложения. Каждое событие получает новый случайный технический код без общего идентификатора пользователя, устройства или сеанса. Страна магазина App Store проверяется для доступности функции и включается в события как обозначение рынка; это не ваше физическое местоположение. Мы не отправляем рекламные идентификаторы, постоянные идентификаторы устройства или GPS-координаты. При передаче запроса сетевые сервисы неизбежно получают ваш IP-адрес; сохранение IP-адресов в статистике и определение местоположения по ним отключены.

Статистику приложения можно в любой момент выключить в разделе «О iBuben». Это прекращает дальнейший сбор и отправку и удаляет ещё не отправленные события с устройства. Уже полученные события при этом автоматически не удаляются. Статистика хранится только столько, сколько разумно необходимо для понимания и улучшения приложения. Запросить удаление можно через «Связь с разработчиком» или по указанной ниже электронной почте; поскольку события не связаны с вашим именем или учётной записью, мы можем не найти конкретное прошлое событие.

Необязательные уведомления

Если вы согласитесь получать уведомления, основное приложение будет использовать Firebase Cloud Messaging (FCM) и службу push-уведомлений Apple (APNs), чтобы изредка присылать новости и полезные советы. Эти службы обрабатывают токен APNs, идентификатор установки приложения Firebase и технические данные, необходимые для адресации, доставки и диагностики уведомлений: модель устройства, язык, часовой пояс, версию операционной системы, идентификатор и версию приложения. FCM также может обрабатывать не связанные с личностью сведения о доставке и диагностике. Модуль Firebase Analytics подключён только в основном приложении, а сбор данных отключён. Расширение клавиатуры не использует SDK Firebase для уведомлений или аналитики, а службы уведомлений не получают текст клавиатуры, запомненные слова, подсказки, содержимое буфера обмена или сведения об использовании клавиатуры.

Уведомления необязательны. Их можно отключить в iBuben или настройках iOS. После отказа в iBuben приложение отключает обмен сообщениями и запрашивает удаление регистрационного токена FCM и подписки на тему. Если устройство временно не подключено к сети, очистка будет повторена позже.

Обратная связь, поддержка и приложение «Фото»

Если вы отправляете отзыв, указанные вами имя, адрес электронной почты, категория и текст сообщения, язык и версия приложения, а также выбранное вами вложение передаются только для доставки обращения, диагностики проблемы и ответа. Обращения направляются через Google Apps Script и почтовые сервисы Google. При прямом обращении к разработчику сообщение также обрабатывается вашим почтовым сервисом по его правилам. Эти сведения не используются для рекламы или отслеживания.

Если вы решите сохранить изображение для истории, iBuben запросит доступ только на добавление в приложение «Фото», чтобы сохранить подготовленный файл. iBuben не читает, не сканирует и не загружает вашу медиатеку. При добавлении изображения к отзыву обрабатывается только файл, который вы явно выбрали для этого обращения.

Покупки, подписки и премиум-доступ

Покупки и подписки обрабатываются Apple через StoreKit. iBuben не получает ваш Apple ID, данные платёжной карты или банковского счёта и другие платёжные реквизиты.

Подходящим пользователям также может предоставляться однократный 7-дневный App Trial. App Trial предоставляется iBuben отдельно от вводного предложения подписки Apple, начинается только после явного выбора пользователя, не создаёт покупку или подписку, не списывает деньги и не продлевается автоматически. Подписки, в том числе Monthly и Yearly, и покупка Lifetime остаются отдельными встроенными покупками Apple. Если Apple отдельно показывает вводное предложение для Yearly, оно является частью подписки, а условия оплаты и продления отображаются в окне подтверждения Apple.

Для определения права на App Trial, проверки премиум-доступа, восстановления покупок и обработки продлений, состояния оплаты, возвратов или отзывов доступа основное приложение и сервис проверки покупок iBuben могут обрабатывать подписанные Apple данные App Transaction, транзакций, продлений и App Store Server Notification. Они могут включать созданные Apple идентификаторы транзакции приложения, транзакции и исходной транзакции; идентификатор продукта; среду App Store; даты покупки и окончания; сведения о льготном периоде, оплате, типе владения и отзыве доступа; а также статус обработки уведомления. Сервис размещён в Google Cloud/Firebase и может обращаться к App Store Server API Apple. Эти записи не содержат текст клавиатуры, Apple ID, рекламные идентификаторы, платёжные реквизиты или цифровой отпечаток устройства.

Право на App Trial связывается с подтверждённым Apple идентификатором транзакции приложения для Apple Account, используемой в разделе «Медиаматериалы и покупки». iBuben получает подписанный Apple идентификатор уровня учётной записи, но не Apple ID, имя или адрес электронной почты. Это позволяет сохранять историю App Trial той же учётной записи после переустановки приложения и при переходе на другое устройство.

Сведения об истории покупок и пробного периода хранятся столько, сколько разумно необходимо для предоставления и восстановления доступа, сохранения права и истории использования App Trial и истории любых предложений Apple, обработки продлений, возвратов и отзывов, предотвращения мошенничества или повторного использования пробного периода, а также выполнения требований безопасности и закона. Удаление или повторная установка приложения не удаляет историю покупок Apple и эти необходимые записи о доступе. Отмена подписки и управление историей покупок Apple выполняются через Apple.

Сервис покупок ведёт закрытые служебные отчёты о подписках, пробных периодах и покупках. Разработчику могут поступать ограниченные уведомления через Telegram: условный номер покупателя или код события, тариф, сумма и валюта при наличии у Apple, страна магазина App Store, даты и состояние продления. Они не содержат ваш Apple ID, имя, email, платёжные реквизиты или текст клавиатуры. Эта обработка сервиса покупок отделена от добровольной статистики использования приложения и не управляется её переключателем.

Поставщики услуг и международная обработка

В зависимости от выбранной функции данные могут обрабатываться Apple (StoreKit, APNs и iCloud Drive), Google/Firebase/Google Cloud (загрузка языков, уведомления, размещение сервисов, применение лимитов и проверка покупок), Google Apps Script и почтовыми сервисами (обратная связь), Yandex Cloud Translate (перевод), PostHog EU (необязательная статистика приложения) и Telegram (закрытые уведомления сервиса покупок). Обработка может происходить за пределами вашей страны. Мы используем этих поставщиков только для предоставления описанных выше функций с учётом применимых условий этих сервисов и правил обработки данных. Мы не разрешаем использовать текст клавиатуры или другое отправленное содержимое для рекламы iBuben или отслеживания пользователей в разных приложениях.

Хранение, удаление и ваш выбор

Вы можете удалить запомненные слова и сбросить данные клавиатуры в приложении, удалить резервные копии из выбранного места, отключить Переводчик, уведомления или статистику приложения в iBuben, а также изменить разрешения для «Полного доступа», приложения «Фото» и уведомлений в настройках iOS. Данные, отправленные через форму обратной связи, хранятся только столько, сколько разумно необходимо для ответа, решения проблемы и выполнения требований безопасности или закона.

Задать вопрос или запросить удаление данных, находящихся под контролем iBuben, можно по адресу ibuben.support@gmail.com. Некоторые сведения могут потребоваться для сохранения целостности покупок или пробного периода, выполнения запроса, предотвращения злоупотреблений или соблюдения закона. Данные, которыми управляют Apple, Google, Yandex, ваш почтовый сервис, «Файлы» или iCloud, необходимо также контролировать средствами соответствующего поставщика. Не отправляйте в запросе о конфиденциальности текст, набранный на клавиатуре, или платёжные реквизиты.
